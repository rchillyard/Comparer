inline def derived[T](using m: Of[T]): Comparer[T]

Method to derive a Comparer, so that you can write, for a case class:

Method to derive a Comparer, so that you can write, for a case class:

 case class Date(year: Int, month: Int, day: Int) derives Comparer

or, for an enum (or a sealed trait):

 enum Suit derives Comparer:
   case Clubs, Diamonds, Hearts, Spades

For a case class (or any other product type), the fields are compared in order, from the first (most significant) to the last (least significant), and each field type must itself have a given Comparer. If you need a different order, then build the Comparer explicitly, using same and :|.

For an enum or a sealed trait (a sum type), values of different cases are compared by the order in which the cases are declared. Values of the same case are compared using that case's given Comparer if it has one, otherwise using a Comparer derived for that case (i.e., by its fields).

Recursive types (such as a tree whose nodes contain trees) are supported.

Type parameters

T

the underlying type of the result.

Value parameters

m

the Mirror of T, supplied by the compiler.

a Comparer[T].
