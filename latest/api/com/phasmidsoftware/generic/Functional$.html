def tuple2[T1, T2, R](f: T1 => T2 => R): (T1, T2) => R

This method uncurries the first two parameters of a two- (or more-) parameter curried function. The result is a (curried) function whose first parameter is a tuple of the first two parameters of f; whose second parameter is the third parameter, etc.

This method uncurries the first two parameters of a two- (or more-) parameter curried function. The result is a (curried) function whose first parameter is a tuple of the first two parameters of f; whose second parameter is the third parameter, etc.

This method is similar to f.tupled in the Scala library but that method will tuple all parameters of a curried function. Here, we make it explicit how many parameters we wish to tuple.
